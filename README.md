## PDF 是什么样的

- A4 竖版，沿用原版书籍排版；单语独立阅读，双语提供英上中下与中上英下两种顺序。
- 双语目录支持点击跳转，另有 PDF 书签。
- 普通台词的中英配对保持同页；超长文献按所选语言顺序分别全文自然续页。
- 选项分支分别展开，共同接续保留一次；小径按目录位置收录。

这一版通过程序检查，并做了代表页面的视觉抽查；尚未逐页人工校对或完成实纸试印。原始文本中的缺文、资源差异和待核归属也可能保留。

## 格式怎么选

**PDF** 适合保留版式、电脑和平板阅读及打印。小屏电子书设备更适合后续的 **EPUB**；**TXT** 用于兼容性优先的纯文本阅读。

旧 Markdown 已归入本地历史存档，不再作为主要阅读成品维护。本仓库与[雨幕档案在线阅读器](https://rain-archive.pages.dev/)分别维护，版本可能不同。
