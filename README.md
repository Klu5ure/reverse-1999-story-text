# 《重返未来：1999》剧情文本

这是《重返未来：1999》的剧情文本整理，包含简体中文、繁體中文、English、日本語、한국어 五种语言。
正文按章节保存为 Markdown，在浏览器里点开就能读，不需要安装任何软件。

> [!WARNING]
> **剧透提示：** 本仓库包含主线、活动、角色剧情等完整内容，包括关键情节与结局，请按自己的游戏进度阅读。

每章文档的顶部和底部都有上一章、目录、下一章的链接。

## 关于这份整理

正文由维护者从游戏剧情数据整理生成。**顺序按游戏里的剧情走向还原**，不是配置文件里的行序——
后者常常被打乱甚至整体倒序。选项在选项处展开，逐条分支标出来；分支汇合后的共同结尾只出现一次。
章节归属取自同一份目录数据，没有重新推断。每节的原始编号记在 `structured/sections.json` 里，可以逐条核对。

本仓库只放整理后的文本，**不包含游戏原始资源、拆包文件或生成工具**。

## 缺失与说明

- 五种语言的内容并不完全对等。某一节或某一章在某种语言下缺失时，只写一句说明，
  不拿别的语言顶上，也不会逐行重复占位；只有零散缺句才逐行标出。统计见 `structured/language-gaps.json`。
- 游戏里不显示的日志备用行没有收入。正文中的图片和画面用 `〔图：…〕`、`〔画面：…〕` 标出，图片本身不在仓库里。
- 字号、颜色、注音这类排版标记已经去掉；`<i>`/`<b>`/`<s>` 转成 Markdown 的强调写法。
- 分支展开和未收录的行按小节记在 `structured/scene-coverage.json` 里。
