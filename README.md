# 重返未来：1999 剧情文本

游戏《重返未来：1999》的剧情文本，五种语言各一份：简体中文、繁體中文、English、日本語、한국어。
按章拆成 Markdown 文档，在浏览器里点开就能看。

> [!WARNING]
> 下面全是剧透，关键情节和结局都在里面。建议按自己的游戏进度挑着看。

正文分七类：主线、活动、角色剧情、玩法故事、荒原互动、附加片段、影像附文。
小径是章节地图上的支线读物，不单独存放，按普通小节排进它所属的章节。
每章文档的顶部和底部都有上一章、目录、下一章的链接。

## 这份文本是怎么来的

从游戏剧情数据整理生成。**顺序按游戏里的剧情走向排**，不是配置文件的行序——后者常常被打乱，甚至整个倒过来。
遇到选项就在原地展开，一条条分支标出来；分支重新汇合之后的共同结尾只出现一次。
章节归到哪一类、哪一章，用的是同一份目录数据，没有另行推断；每节的原始编号记在 `structured/sections.json`，可以逐条核对。

这里只有整理后的文字，**没有游戏原始资源、拆包文件，也没有生成工具**。

## 缺了什么

- 五种语言并不完全对等。某节或某章在某种语言下没有正文时，只写一句说明，
  不拿别的语言顶上，也不逐行刷占位；只有零星缺句才逐行标出。统计见 `structured/language-gaps.json`。
- 游戏里不会显示的日志备用行没有收；正文中的图片和画面用 `〔图：…〕`、`〔画面：…〕` 标出，图片本身不在仓库里。
- 字号、颜色、注音这些排版标记已经去掉，`<i>`/`<b>`/`<s>` 换成 Markdown 的强调写法。
- 分支展开情况和没收录的行，按小节记在 `structured/scene-coverage.json`。
